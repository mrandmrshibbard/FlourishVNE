## Description (main body)

# 🌸 FlourishVNE — Visual Novel Engine

**Create stunning visual novels without writing a single line of code.**

FlourishVNE is a free, open visual novel engine with a modern drag-and-drop editor, a massive built-in command library, and instant live preview — all running in your browser or as a desktop app. Build your story, design your menus, and export a playable game in minutes.

---

## ✨ What Makes Flourish Different

### 🎨 Visual UI Screen Editor (WYSIWYG)
Design your title screen, pause menu, save/load screens, and custom menus by **dragging and dropping elements on a visual canvas** — no scripting, no guesswork. Resize, reposition, and style everything visually. Most VN engines don't have this.

### 🧩 37 Built-In Commands
Dialogue, choices, branching, screen effects, character transitions, video playback, credit rolls, scripting — all built in. Organized into color-coded categories and added to your scenes with a simple drag and drop.

### 👤 Multi-Layer Character System
Go beyond single-image sprites. Flourish characters support **compositable layers** — separate body, eyes, mouth, hair, and outfit layers that combine into expressions. Layers can even be **animated videos** for blinking, breathing, or flowing hair effects.

### ⚡ Command Stacking — Run Things Simultaneously
Make a character slide in *while* music starts *while* the screen tints — all at the same time. Flourish's async command stacking lets you run multiple commands in parallel for perfectly choreographed cinematic moments.

### 🌧️ 6 Built-In Screen Overlay Effects
Drop in atmospheric effects with one command:
- **Rain** & **Snow/Ash** — with wind, particle size, and density controls
- **Sunbeams** — warm light rays with spread and color
- **Shimmer** — floating particles with directional flow
- **CRT Scanlines** — retro TV aesthetic
- **Chromatic Glitch** — horror/cyberpunk distortion

All effects are stackable with adjustable intensity, speed, blend mode, and color.

### 🧙 12 Template Systems + Content Wizards
Build complex game systems without coding:
- **Character Creator & Dress-Up** — let players create their own character (choose, dress up, name) or dress up any cast member, with live preview and automatic outfit-fit rules
- **Shop System** — buy/sell with variable-tracked inventory
- **Dating Sim** — relationship stat tracking
- **Combat, Stat Tracker, CG Gallery, Inventory** — and more
- Each wizard walks you through setup step by step and generates all the screens, variables, and elements for you

## 🎮 Full Feature List

### Story & Flow
- 📝 Rich dialogue with character nameplates and variable interpolation (`{playerName}`)
- 🔀 Multiple-choice branching with per-option conditions and multi-action support
- 🏷️ Labels, jumps, and scene transitions (6 transition types)
- 🎭 Collapsible color-coded branches for organizing complex story paths
- 📂 Command groups for visual organization
- ⏱️ Wait commands and timed sequences
- ⌨️ Customizable text input prompts with styled input boxes

### Characters
- Multi-layer compositable sprites with named expressions
- 7 position presets + custom X/Y% positioning
- 7 transition types (fade, slide, dissolve, iris, wipe, instant, cross-fade)
- Per-character custom fonts for nameplates
- Video layers (animated sprite parts)

### Screen & Camera Effects
- Screen shake, flash, tint, and camera pan/zoom
- 6 overlay effects (rain, snow, sunbeams, shimmer, CRT, glitch)
- Live transition previews in the editor

### Audio
- 3 independent channels: Music, SFX, Ambient
- Loop, fade in/out, per-command volume control
- Per-screen music with playback policies (continue, restart, stop)

### Video & Movies
- Fullscreen cutscenes or overlay videos
- Custom positioning, sizing, opacity, and object-fit
- Video backgrounds and video character layers
- Wait-for-completion option for cinematic pacing

### UI / Menu System
- **12 element types**: Button, Text, Image, SaveSlotGrid, SettingsSlider, SettingsToggle, CharacterPreview, TextInput, Dropdown, Checkbox, AssetCycler, CGGallery
- **14 action types**: StartNewGame, GoToScreen, SaveGame, LoadGame, JumpToScene, SetVariable, and more
- Visual drag-and-drop WYSIWYG editor for all screens
- 5 built-in screens (Title, Save, Load, Settings, Pause) — fully customizable
- Game HUD system (always-visible overlay during gameplay)
- Per-element conditions, transitions, and disabled states

### Variables & Logic
- 3 types: String, Number, Boolean
- 3 scopes: Local (per-scene), Global (per-playthrough), Persistent (cross-session)
- 10 condition operators (==, !=, >, <, >=, <=, is true, is false, contains, startsWith)
- Conditions on **any command** — not just if/else blocks
- Variable usage tracker — find every reference across your entire project
- Scene gating — lock scenes behind variable conditions with fallback routing

### Build & Export
- **Web (HTML)**: single-file standalone game — upload directly to itch.io
- **Desktop (EXE)**: standalone executable for Windows/Mac/Linux
- **Installer**: NSIS installer with desktop shortcut
- Pre-build validation (catches missing assets and broken references)
- Full save/load system (10 slots + auto-save) in desktop builds

### Scripting & Plugins
- JavaScript scripting with a sandboxed `game` API
- Variables, navigation, dialogue, audio, math utilities — all accessible from scripts
- Script validation (syntax checking with line-level errors)
- Test execution in a mock sandbox with console output
- Plugin system with install/enable/disable/configure

### Localization
- 10 preset languages (EN, JA, ES, FR, DE, KO, ZH, PT, RU, AR)
- Auto-extraction of translatable strings
- Inline translation editor
- CSV export/import for professional translators

### Credit Roll System
- Structured credit entries (headings + credit pairs)
- Slideshow backgrounds that cycle during credits
- Foreground media overlay with timing controls
- Skip control and on-complete actions

### Accessibility
- High contrast mode
- Reduced motion (auto-detects system preference)
- Large text mode
- Keyboard-only navigation
- Screen reader support

### Editor Experience
- 6 beautiful themes (Rainbow, Midnight, Ocean, Forest, Sunset, Sakura)
- Full undo/redo with keyboard shortcuts
- Multi-window editing — pop out any tab into a separate OS window
- Auto-save with crash recovery
- Guided onboarding tour for new users
- Drag-and-drop command reordering, multi-select (Click/Shift/Ctrl), copy/paste

## 🚀 Get Started in 60 Seconds

1. Download and launch Flourish
2. Click **Create New Project**
3. Drag a **Dialogue** command into your scene
4. Type your text — watch it appear in the live preview
5. Hit **Build** → **Web** → upload to itch.io

That's it. Your visual novel is live.
